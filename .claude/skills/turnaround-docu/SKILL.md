# 기업 역전 다큐 (Turnaround Docu) 구조 스킬

레퍼런스: 「"400대 팔고 적자였습니다" 현대차가 1조에 사 온 로봇 회사에 5년간 벌어진 일」(22:35, 역사한끗)
비트별 상세 분석·타임스탬프는 `references/source-analysis.md` 참고 (설계 단계에서 1회 Read).

**원칙: 구조와 기법만 가져온다. 레퍼런스 문장·조어("공장 지참금" 등)를 그대로 쓰지 않는다. 주제마다 새 조어를 만든다.**

---

## 0. 이 구조가 맞는 주제인지 판별

아래 5개 중 4개 이상이면 적합. 미달이면 사용자에게 알리고 다른 구조를 제안한다.

1. **역설**: 대상이 기술/명성은 최고인데 상업적으로 실패한 이력이 있다
2. **거물의 포기**: 더 크고 유명한 주체(빅테크·글로벌 투자사 등)가 먼저 갖고 있다가 놓았다
3. **숫자 3종 세트**: 과거 가치 → 투입액 → 현재 가치를 확인 가능한 숫자로 댈 수 있다
4. **뉴스 페그**: 최근 1~2주 내 발표·계약·행사 등 "어제/이번 주" 훅이 있다
5. **역사 거울**: 같은 주체가 수십 년 전 비슷한 방식으로 성공한 사건이 있다 (수미상관용)

## 1. 핵심 논지 설계 (작성 전에 반드시 확정)

다음 빈칸을 채운 **한 문장**을 먼저 만든다. 모든 비트는 이 문장을 증명·반박·확장하는 데만 쓴다.

> "○○을 가진 쪽이 아니라, ○○을 줄 수 있는 쪽이 이긴다."
> (예시 틀: 기술 vs 쓸 자리 / 자본 vs 현장 / 아이디어 vs 유통망)

함께 정할 것:
- **비교축 거물 1~2곳**: 영상 내내 반복 소환할 대조 대상
- **화자 조어 2개**: 핵심 개념 이름 1개(중반) + 경쟁자 대조 개념 1개(후반)
- **제목 숫자**: 영상 중 가장 의외의 실패 숫자 (조회를 끄는 건 성공 숫자가 아니라 실패 숫자)

## 2. 18비트 구조 (러닝타임 비중)

러닝타임 T분 기준으로 비중을 곱해 분량을 배정한다. 20분 = 약 1만 1천~1만 2천 자.

### 도입부 (10%)
1. **숫자 충격 콜드오픈 (4%)** — "A가 B가 됐습니다. N년 만에요. N배입니다." → 누구나 한 번쯤 본 장면으로 대상 소개 → 역설(최고인데 못 벌었다) → 거물 둘이 포기 → 한국 기업이 샀다 → "그리고 어제…" 뉴스 페그
2. **헤드라인 낭독 (3%)** — 최신 발표를 명사형 종결 전보체로 나열("2028년부터 ○○ 투입. 연 N대 생산.") → "세계 최초" 류 의미 부여 → 숫자 3종 세트 1회차
3. **핵심 질문 + 논지 + 역사 떡밥 (3%)** — "왜 ○○은 못 했을까요?" → 소거법("돈이 없어서가 아니에요. 기술도 아니고요. 없었던 건 딱 하나") → 답 한 단어 → 논지 → 수십 년 전 사건 한 줄 떡밥 + "끝까지 보시면 이어지는 게 보이실 겁니다"

### 1막: 왜 실패했나 (25%)
4. **기원 + 1차 실패 (11%)** — 창업자·출신 연구실(이름을 우리말로 풀기) → 어떻게 유명해졌나 → 거물 인수 "여기까지는 완벽하죠" → "근데 이상한 게 하나 있어요" 매각 → 외신이 짚은 이유 → 내부 갈등 → **왜 어려운 문제인가**를 대비로 설명(한 번 성공 vs 매일 반복)
5. **2차 실패 + 제목 숫자 (9%)** — 두 번째 주인의 노력 → 제품·가격(원화 환산) → **제목 숫자 공개** → 현재 계획 대비 규모 비교 → 인수 당시 회의론 기사 제목 인용 → "솔직히 그 걱정에 근거가 아주 없진 않았어요" (공정성)
6. **오해 바로잡기 + 재정의 (5%)** — "○○이 무능해서가 아닙니다" → 각 거물의 본업 재정의 → **일상 비유 1개** → 한 줄 정리 → 대비 컷: "그런데 지구 반대편에…"

### 2막: 무엇이 달랐나 (40%)
7. **딜 구조 디테일 (5%)** — 지분 배분 % → 오너 개인 리스크(스킨 인 더 게임) → 계약 조항이 실제로 발동된 이야기
8. **핵심 개념 네이밍 (10%)** — "그런데 진짜는 그다음이에요" → **화자 조어 ①**("저는 이걸 ○○라고 부르고 싶습니다" + 생활 비유) → 구성 요소를 "먼저 / 다음은 / 그리고"로 하나씩 → 전문가 인용 → 전문 개념 쉬운 풀이 → 거물이 못 한 이유와 다시 연결 → 규모 숫자 → 경영진 발언 인용
9. **숫자 결산 + 오해 방지 (4%)** — 투입액 항목별 합산 → 현재 가치 → N배 (숫자 3종 세트 2회차) → "기술이 갑자기 좋아진 게 아닙니다. 달라진 건 ○○뿐"
10. **증거 ① 제품 스펙 (5%)** — 행사를 모르는 사람 기준으로 소개 → 스펙마다 **생활 단위 번역**(무게→쌀 포대, 길이→성인 팔 길이, 온도→한겨울 새벽) → "이 스펙은 전부 ○○용" → 논지 재확인
11. **증거 ② 최신 발표 + 현장 (9%)** — 발표 원문 재낭독 → 연간 수치를 하루 단위로 환산 → 시설을 친숙한 사물로 비유(예: 직업훈련소) → 구체 항목 수·예시 → "두 배도 세 배도 아니고 N배" → 최종 목표를 신입사원 비유로
12. **아이러니 반전 (5%)** — "기억하시죠?" 앞에서 포기한 거물이 지금 이쪽 제품을 산다/협력한다 → 이유 → 상대 측 인용 → **대구 문장**("N년 전 ○○이 놓았던 X는 지금 한국 것이 됐고, 그 ○○은 지금 한국 Y를 사 갑니다")
13. **부가 발표 랩업 (7%)** — 나머지 발표를 빠르게 → "본업을 놓은 게 아니라 오히려 더 세게 잡았다"

### 3막: 냉정하게 (10%)
14. **경쟁자 대조 (4%)** — 대표 경쟁자의 큰 약속 vs 실제 실적 → **화자 조어 ②**(예: 크기 vs 밀도) → 경영진 비전 인용
15. **김 빼기 (5%)** — "여기까지 들으면 다 이긴 싸움 같죠? 근데 냉정하게" → 아직 안 된 것, 남은 기간, 외부 리스크 → 시장 반응(주가·목표가 격차) → "몸값은 기대가 붙인 값" → "이제 겨우 링에 올라간 겁니다"
16. **결론 한 줄 (1~2%)** — 논지 재진술 + "N원에 산 건 X가 아니었습니다. Y였어요."

### 엔딩 (8~10%)
17. **역사 수미상관 (6~7%)** — "그런데 저는 이 그림이 낯설지가 않습니다" → 떡밥으로 던진 과거 사건 전개 → 당시 아무도 안 믿었다(지금 의심과 결이 같다) → 이후 성장 숫자 → "이번에도 똑같습니다" + 과거↔현재 1:1 대응 → 그 현장에 있던 사람들 상상 장면 → 미래 첫 장면으로 연결
18. **질문형 CTA + 후속 약속 (2~3%)** — 이분법 질문("우리는 A인 나라가 될까요, B인 나라가 될까요?") → 둘의 차이 한 줄 → 댓글 요청 → "그날이 오면 이 이야기부터 다시 들고 오겠습니다"

## 3. 문체 규칙

- **존댓말 구어체**, "~습니다"와 "~예요/거든요/잖아요"를 섞는다. 한 문장 25자 내외, 길어도 40자.
- **숫자 바로 뒤에 의미**: 큰 숫자는 반드시 원화 환산·생활 단위·하루 단위 중 하나로 번역.
- **질문 → 즉답** 패턴: "왜 팔았을까요? 이유는 하나로 모입니다."
- **섹션 전환어**: "자, 여기서", "그런데 진짜는 그다음이에요", "여기서 재밌는 게 하나 있습니다", "근데 여기서 김을 좀 빼야 할 게 있습니다".
- **풀이어**: "이게 무슨 얘기냐면요", "이게 어느 정도냐면요", "쉽게 말하면" → 직후 비유.
- **강조 반복**: "두 배도 세 배도 아니고 열 배예요", "돈을 준 게 아니라 자리를 준 거예요."
- **화자 1인칭은 2~3회만**: "저는 ~라고 부르고 싶습니다", "저는 ~를 기다리고 있습니다".
- **인용은 출처 유형을 섞는다**: 당시 기사 제목, 외신, 애널리스트, 자사 경영진, 상대 회사 경영진. 인용은 짧게 의역.
- **금지**: 투자 권유·종목 매수 뉘앙스, 근거 없는 "세계 최초/최고", 경쟁사 조롱, 출처 없는 숫자.
- TTS 대비: 숫자는 읽히는 형태로("2만 5천 대"), 영문 약어는 첫 등장 시 풀이.

## 4. 리텐션 체크포인트

- 00:00–00:10에 숫자 충격, 02:00 전에 역사 떡밥 + "끝까지 보시면".
- 약 2~3분마다 섹션 전환어로 새 질문을 연다.
- 비교축 거물을 최소 5회 재소환(오프닝·1막·재정의·개념·반전·결론).
- 숫자 3종 세트를 오프닝·중반 결산·결론에서 3회 반복 (매번 다른 문장으로).
- 70% 지점에 김 빼기 → 국뽕 피로감 해소 + 신뢰 확보.
- 마지막 2분에 떡밥 회수.

## 5. 산출물 워크플로우

요청을 받으면 순서대로 진행한다. youtube-pd 파이프라인 안에서 쓰일 때는 OUTLINE/DRAFT/REVIEW 단계에서 이 문서를 구조 가이드로 사용한다.

1. **판별**: §0 체크 → 결과를 사용자에게 한 줄 보고
2. **리서치**: WebSearch로 숫자 3종 세트, 매각·인수 시점 기사 제목, 최신 발표 원문, 경쟁자 약속 vs 실적, 주가·목표가, 역사 거울 사건의 연도·숫자 수집. 각 숫자에 출처 URL 기록.
3. **설계 시트** (사용자 확인용): 논지 한 문장 / 비교축 거물 / 조어 2개 / 제목 숫자 / 역사 거울 / 러닝타임별 18비트 분량표
4. **대본 작성**: 18비트 순서로 순수 텍스트. 비트 경계는 빈 줄로만 구분(헤더 없이).
5. **자체 검수**: §6 체크리스트
6. **메타**: 제목 3안 + 설명글 + 해시태그 5개

## 6. 검수 체크리스트

- [ ] 논지 한 문장이 결론(비트 16)에서 거의 그대로 재진술되는가
- [ ] 첫 10초 안에 숫자 충격이 있는가
- [ ] 역사 떡밥(비트 3)이 비트 17에서 회수되는가
- [ ] 큰 숫자마다 생활 단위 번역이 붙었는가
- [ ] 모든 숫자·인용에 출처가 있는가 (리서치 노트와 대조)
- [ ] 거물을 깎아내리지 않고 "본업이 달랐다"로 재정의했는가
- [ ] 김 빼기 섹션에 구체 리스크 3개 이상 + 시장 반응 숫자가 있는가
- [ ] 화자 조어 2개가 레퍼런스와 다른 새 표현인가
- [ ] 투자 권유로 읽힐 문장이 없는가
- [ ] 18비트 비중이 러닝타임 대비 ±3%p 안에 있는가

## 7. 메타 템플릿

- **제목**: `"[의외의 실패 숫자를 담은 짧은 인용]" [주체]가 [가격]에 사 온 [대상]에 [기간]간 벌어진 일`
  - 변형: `[거물]이 버린 [대상], [주체]가 [기간] 만에 [N배]로 만든 방법`
- **설명글**:
  ```
  [숫자 3종 세트 + 논지를 담은 2~3문장]

  📌 이 영상에서 다루는 내용
  · [비트 순서대로, 항목마다 핵심 숫자 1개]
  ...

  🔗 출처 리스트
  [언론사] — [기사 제목] [URL]
  ```
- **해시태그**: 주체 / 대상 / 제품 / 인물 / 산업 키워드 5개
