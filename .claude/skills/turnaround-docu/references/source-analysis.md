## 반복 등장하는 장치

- **숫자 3종 세트**: 과거 가치 → 투입액 → 현재 가치. 오프닝·중반 결산·결론에서 세 번 반복.
- **거물 대비**: 구글/소프트뱅크가 오프닝, 1차 실패, 재정의, 플라이휠, 아이러니 반전, 결론에 계속 재등장 → 비교축이 하나로 고정.
- **"자, 여기서 ~"** 전환어로 섹션 경계 표시 (7회 이상).
- **"이게 무슨 얘기냐면요 / 어느 정도냐면요"** → 즉시 쉬운 말로 풀이.
- **소거법**: "돈이 없어서가 아니다. 기술이 모자라서도 아니다. 없었던 건 딱 하나."
- **화자 조어**: "공장 지참금", "약속의 크기와 밀도" — 개념에 이름을 붙여 기억에 남게.
- **인용 출처 다양화**: 기사 제목, 외신, 애널리스트, 자사 경영진, 상대 회사 CEO.
- **공정성 장치**: 당시 회의론 인정, 경쟁자 존중, 김 빼기 섹션 → 국뽕이 아닌 "분석"으로 신뢰 확보.
