# 채널 프로필

## 장르
가상시나리오

## 장르 설명
"만약 지구의 자전이 멈추면?", "만약 조선이 쇄국을 하지 않았다면?" 같은 가상의 전제를 세우고 과학적/역사적 근거를 바탕으로 논리적으로 추론해나가는 사고실험 장르.

## 타겟 시청자
"만약에~" 상상을 좋아하는 호기심 많은 사람. 과학/역사 지식을 재미있게 접하고 싶은 학생이나 직장인. 쿠르츠게작트, What If 같은 콘텐츠를 즐기는 시청자. 친구들이랑 "이거 어떻게 될까?" 떠들기 좋아하는 사람.

## 톤앤매너
- 분위기: 흥미진진한 탐구. 과학 선생님이 수업 시간에 "자 오늘 재밌는 거 해볼까?" 하면서 시작하는 느낌. 지적 유희를 즐기되 가볍고 활기차게
- 속도감: 빠른 전개. 전제를 빠르게 세우고 → 1차 결과 → 2차 파급 → 극단적 결론까지 속도감 있게 달림
- 감정 밀도: 낮음 — 감정보다 논리와 재미에 집중. 놀라운 결론에서 "이게 진짜 가능합니다" 정도의 반응만

## 말투 규칙
- 어미: ~합니다체. 친근하면서도 정보 전달력 있게. "~하게 됩니다", "~일까요?", "~라고 합니다"
- 금지 표현: "당연히", "무조건", "확실히" 등 과도한 단정 (가상 시나리오이므로 불확실성 인정), 논문체, 어려운 전문용어 설명 없이 사용
- 호칭: 사용하지 않음. 다만 "한번 생각해 봅시다", "같이 따라가 봅시다" 같은 동참 유도 표현은 가능

## 러닝타임 가이드
- 기본: 15분
- 최소: 10분
- 최대: 22분

## 팩트체크
true

## 리서치 지침
- 가상 전제를 뒷받침할 실제 과학 원리/역사적 사실을 조사 — "지구 자전 속도는 시속 1,670km입니다"
- 관련 학술 논문, 과학 저널, 전문가 인터뷰 등에서 근거 확보
- 유사한 사고실험이 이미 있었는지 확인 (페르미 역설, 트롤리 딜레마 등)
- 수치가 등장하면 단위와 규모를 검증 — 시청자가 "진짜?" 하고 찾아볼 수 있으므로 정확해야 함
- 반론이나 다른 시나리오 분기점도 조사해 영상 내에서 언급

## 스토리텔링 특성
- "만약 ~한다면?" 질문을 던지고 → 즉각적 결과 → 연쇄 반응 → 최종 결론 순으로 단계적 전개
- 단계마다 "여기서 끝이 아닙니다" 식의 전환으로 시청자의 호기심을 계속 끌어감
- 복잡한 과학/역사 개념은 비유와 스케일 비교로 직관적으로 설명 — "이건 서울에서 부산까지 거리의 400배입니다"
- 중간에 분기점을 제시 — "여기서 두 가지 시나리오로 나뉩니다" — 선택지 느낌 부여
- 마무리에서 "실제로 이런 일이 일어날 가능성은?" 현실 연결고리를 던져 여운과 댓글 유도

## 콘텐츠 제약
- 가상 시나리오임을 영상 초반에 명확히 밝힘 — "이건 사고실험입니다"
- 과학적 근거가 있는 부분과 추측 영역을 구분해서 표현 — "과학적으로 확인된 건 여기까지이고, 여기서부턴 추론입니다"
- 전쟁, 대량 사망 등 민감한 시나리오는 구체적 피해 묘사보다 구조적 영향에 초점
- 특정 국가/민족/종교를 비하하는 결론으로 흘러가지 않게 주의
- 공포를 조장하는 종말론적 톤 지양 — 호기심과 탐구의 톤 유지
