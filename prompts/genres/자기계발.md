# 자기계발 — 장르 전문 가이드

youtube-pd 파이프라인에서 자기계발 장르일 때 로드되는 참고 문서.
DATA_PREP, OUTLINE, DRAFT, REVIEW 단계에서 자기계발 고유의 작법·근거·감정설계를 제공한다.

---

## 1. 리서치 방향 (DATA_PREP에서 data-researcher에게 전달)

### 핵심 개념 출처 확인
- 주제와 관련된 원서/원저자 파악
  - 해당 개념을 처음 제시한 연구자/저자
  - 원서 제목, 출간 연도, 핵심 주장
  - 원저자가 아닌 경우 "~에서 영감을 받은 개념"으로 처리

### 연구/근거
- 심리학 실험 (실험 설계, 참가자 수, 결과)
- 뇌과학/행동경제학 연구 결과
- 통계 데이터 (출처 명시 가능한 것)
- 유명 인물의 실제 사례 (성공/실패 스토리)

### 실생활 맥락
- 직장인/학생/프리랜서 등 타겟별 적용 시나리오
- 한국 사회 특유의 맥락 (야근 문화, 취업 경쟁, N잡 등)
- 계절/시기별 맥락 (새해 목표, 이직 시즌, 시험 기간 등)

### 반론/한계
- 해당 개념에 대한 비판적 시각
- "이런 상황에서는 안 통한다" 케이스
- 오해하기 쉬운 포인트

### 관련 프레임워크
- 같은 주제를 다룬 다른 접근법 (비교 소재)
- 보완적 개념 (함께 쓰면 효과적인 것)

## 2. 서사 구조 가이드 (OUTLINE에서 참고)

### 자기계발 기본 서사 구조

| 구조 | 설명 | 적합한 주제 |
|------|------|-------------|
| **문제→원인→해법** | 공감할 만한 문제 제시 → 숨겨진 원인 분석 → 실행 가능한 해법 | 습관, 시간관리, 생산성 |
| **통념파괴형** | "당신이 알던 것은 틀렸다" → 왜 틀렸는지 → 진짜 답 | 동기부여, 성공학 비판 |
| **스토리+교훈형** | 인물/사례 이야기 → 핵심 원리 추출 → 적용법 | 인물 사례, 기업 사례 |
| **단계별 가이드** | Step 1→2→3 순차 진행 → 마무리에 전체 조감 | 구체적 스킬, 루틴 설계 |

### 씬 구성 원칙

- **공감 선행**: 시청자의 현재 고통/불만/욕구를 먼저 건드린 뒤 해법으로 진입
- **공감에 시간 할애**: 전체 분량의 10~15%를 초반 공감 구간에 투자
- **클라이맥스 위치**: 전체의 70~80% 지점 (가장 강력한 인사이트 또는 반전)
- **결말 비중**: 전체의 10~15%. 핵심 요약 + "오늘부터 할 수 있는 한 가지"

### 감정 아크 패턴

| 패턴 | 흐름 | 적합한 주제 |
|------|------|-------------|
| **각성형** | 불편함→의문→충격→이해→결심 | 통념 파괴, 마인드셋 |
| **공감→해방형** | 고통→"나만 그런 게 아니구나"→원인→해법→해방감 | 불안, 번아웃, 자존감 |
| **도전형** | 호기심→시도→실패→깨달음→재시도→성취 | 습관, 스킬 습득 |
| **분석형** | 궁금증→데이터→패턴 발견→인사이트→적용 | 연구 기반, 통계 기반 |

## 3. Hook 패턴 (STRATEGY에서 참고)

**최우선 원칙: 제목이 건넨 약속을 Hook에서 즉시 이행한다.** 아래 패턴은 보조 기법일 뿐, 제목→Hook 연결보다 우선하지 않는다.

| 패턴 | 예시 | 효과 |
|------|------|------|
| **통념 부정** | "노력하면 된다는 말, 과학적으로 틀렸습니다." | 인지 부조화 → 호기심 |
| **숫자+결과** | "이걸 21일만 해봤더니, 하루가 26시간이 됐습니다." | 구체성+기대감 |
| **질문형** | "왜 새해 목표의 92%는 실패할까요?" | 자기 투영 |
| **권위 인용** | "하버드 75년 추적 연구가 밝힌 단 하나의 답." | 신뢰+기대 |
| **고백형** | "저도 3년간 이걸 잘못하고 있었습니다." | 진정성+공감 |

## 4. 문체 규칙 (DRAFT에서 script-writer에게 전달)

### 서술체
- 기본: `~입니다/~합니다` 존댓말 서술체
- 강조 시: `~거든요`, `~잖아요` 등 구어체 가미
- 핵심 문장: 짧고 단정하게. `그게 바로 핵심입니다.`

### 금지 표현
- "구독 좋아요" (영상 마지막 CTA 제외)
- 근거 없는 단정: "무조건", "100%", "반드시 성공"
- 상대방 비하: "이것도 모르면", "당연한 건데"
- 과도한 자극: "충격적", "소름끼치는" (자기계발 맥락에서)

### 설명 원칙
- **비유로 이해시키기**: 추상적 개념 → 일상 비유로 전환
  - 나쁜 예: "인지 부조화란 두 가지 모순된 인지가 공존할 때 느끼는 불편함입니다"
  - 좋은 예: "다이어트 중인데 치킨을 시켰을 때 느끼는 그 찝찝함, 그게 인지 부조화입니다"
- **사례로 체감시키기**: 원리 설명 후 즉시 구체적 사례
- **데이터는 맥락과 함께**: 숫자만 나열하지 말고 "그러니까 이게 뭐냐면" 식으로 해석

### 대화/인용 규칙
- 연구자 인용: "대니얼 카너먼은 이렇게 말했습니다"
- 가상 독자 대화: "이쯤 되면 이런 생각이 들 수 있습니다. '그래서 어쩌라고?'"
- 사례 속 인물 대화: 실제 인터뷰/발언이면 출처 명시

### 속도감
- 공감 구간: 천천히, 감정을 충분히 건드리기
- 원리 설명: 적당한 속도, 비유로 환기
- 실전 적용: 빠르고 구체적으로. 문장 짧게
- 마무리: 다시 천천히, 여운 있게

## 5. 리텐션 장치 (OUTLINE/DRAFT에서 활용)

### 오픈루프
- 2~3분 간격, 새 섹션 진입 전에 배치
- 예: "이게 왜 중요한지는 잠시 후에 말씀드리겠습니다"
- 자기계발에서 효과적인 패턴: "그런데 여기서 대부분이 놓치는 게 하나 있습니다"

### 반전/인사이트
- 예상과 다른 연구 결과, 통념 뒤집기
- 예: "실은 의지력은 근육이 아닙니다. 최신 연구는 정반대를 말합니다"

### 자기 투영
- 시청자가 자신의 상황을 떠올리게 하는 질문
- 예: "혹시 여러분도 매일 아침 알람을 5번 이상 미루고 있지 않나요?"

### 사례 전환
- 추상적 설명이 길어지면 즉시 구체적 사례로 전환
- "실제로 이런 사람이 있었습니다" → 이야기 모드 진입

### 시각화 유도
- "한번 상상해보세요" → 미래 모습 그리기
- 효과: 감정적 동기 부여 + 집중력 회복

## 6. 검수 체크리스트 (REVIEW에서 script-reviewer에게 추가 전달)

> 기본 체크리스트(`prompts/script-review-checklist.md`)에 **추가**하여 적용.

### 논리 완결성
- [ ] 주장→근거→사례→적용이 논리적으로 연결되는가
- [ ] 근거 없는 단정이 없는가
- [ ] 반론/한계를 공정하게 다뤘는가
- [ ] "그래서 어쩌라고?"에 대한 답이 있는가 (실행 가능한 테이크어웨이)

### 톤·공감
- [ ] 시청자를 가르치려 드는 느낌이 아닌가 (코치 톤, 강사 톤 자제)
- [ ] 공감 구간이 충분한가 (문제 제시 후 바로 해법으로 넘어가지 않았는가)
- [ ] 비유와 사례가 타겟 시청자에게 와닿는가
- [ ] 금지 표현이 없는가

### 근거 품질
- [ ] 인용한 연구/데이터의 출처가 명시 가능한가
- [ ] 오래된 연구를 최신인 것처럼 다루지 않았는가
- [ ] 상관관계를 인과관계로 오해시키지 않는가

### 리텐션
- [ ] 2~3분 간격으로 리텐션 장치가 배치되었는가
- [ ] 오픈루프가 적절히 열리고 닫히는가
- [ ] 감정 아크가 설계대로 흐르는가
- [ ] 자기 투영 질문이 충분한가

### TTS 최적화
- [ ] 전문 용어를 쉽게 풀어썼는가
- [ ] 문장 호흡이 자연스러운가 (TTS가 끊어 읽기 좋은 길이)
- [ ] 영어 용어는 한글 병기했는가

## 7. 콘텐츠 제약

- 의학적 조언 금지 (우울증, ADHD 등은 "전문가 상담 권장" 명시)
- 특정 종교/정치 관점 배제
- 수익/성과 보장 표현 금지 ("이걸 하면 연봉이 2배" 등)
- 타인 비교/비하 금지 ("성공한 사람은 이렇게 하는데 당신은..." 식)
- 출처 불명확한 명언은 "~라는 말이 있습니다"로 처리 (저자 확인 안 되면 단정 금지)
