# YouTube 업로드 정보 생성

`_script/outline.md` + `_script/concept.md`를 읽고 업로드용 제목/설명글/태그를 생성합니다.

---

## 입력 (파이프라인 컨텍스트에서 자동 확보)

- `{P}/_script/outline.md` — 영상 구조, 파트별 내용, 핵심 약속
- `{P}/_script/concept.md` — 크리에이티브 전략, 앵글, 핵심 메시지
- `channels/{channel}/config/settings.json` — 채널 메타 정보 (name, type, target, tone)

---

## 실행 절차

### 1. 파일 읽기
1. **outline.md** 읽기 → 영상 구조, 파트별 내용, 핵심 약속, 데이터 출처 파악
2. **concept.md** 읽기 → 앵글, 핵심 메시지, 감정 전략 파악
3. **settings.json** 읽기 → 채널 톤/타겟 참고

### 2. youtube.md 생성

`{P}/output/youtube.md`에 저장:

```markdown
# 업로드 정보

## 제목
{제목}

## 설명글
{설명글 전체 텍스트}

## 태그
#태그1, #태그2, #태그3, ...

## 고정 댓글
{고정 댓글 텍스트}
```

---

## 생성 규칙

### 제목
- outline의 **핵심 약속**과 **훅**에서 핵심 궁금증 추출
- **40~70자** 이내
- 숫자, 구체적 사실 포함 (예: "6,500원", "200원", "500억")
- 궁금증 유발 구조: 반전, 질문, 충격적 사실
- 이모지 사용 금지 (제목에는)

### 설명글

다음 섹션을 순서대로 포함:

1. **키워드** (맨 첫 줄)
   - 영상 핵심 키워드 5개를 `#키워드1, #키워드2, ...` 형식으로 나열
   - 검색 노출용, 설명글 최상단에 배치

2. **한줄 요약** (1~2문장)
   - 영상의 핵심 내용을 압축
   - 검색 노출용 키워드 자연스럽게 포함

3. **📌 이 영상에서 다루는 내용** (bullet points)
   - outline의 각 파트에서 핵심 포인트 1줄씩 추출
   - 6~10개 항목
   - 구체적 숫자/사실 포함

4. **💡 참고 데이터 출처** (1~2줄)
   - outline에 명시된 데이터 출처 나열
   - 없으면 이 섹션 생략

5. **🔔 CTA** (1줄)
   - 구독/좋아요 유도 문구
   - 채널 톤에 맞게

### 태그
- 영상 주제와 관련된 키워드 10~15개
- 대주제 → 소주제 → 관련 검색어 순서
- 각 태그 앞에 `#` 붙이고 쉼표(,)로 구분 (예: `#경제, #한국경제, #GDP`)

### 고정 댓글
- 크리에이터가 영상 업로드 직후 **직접 다는 첫 번째 댓글**
- 목적: 시청자 참여 유도 (댓글 수 ↑, 알고리즘 부스트)
- **1~3문장**, 짧고 임팩트 있게
- 채널 톤/대상에 맞는 말투 사용 (settings.json의 tone 참고)

**유형 (영상 내용에 따라 자연스럽게 선택):**

| 유형 | 예시 |
|------|------|
| 의견 질문 | "여러분은 어떻게 생각하세요? 솔직히 저는 좀 충격이었는데..." |
| 경험 공유 요청 | "혹시 이거 직접 경험해본 분 계세요? 댓글로 알려주세요!" |
| 선택지 제시 | "A vs B, 여러분이라면 어느 쪽 선택하실 건가요?" |
| 가벼운 어그로 | "이거 모르고 있었으면 진짜 큰일 날 뻔했네요..." |
| 반전/떡밥 | "사실 이 영상에서 다 못한 이야기가 하나 더 있는데..." |
| 퀴즈/예측 | "영상 보기 전에 맞춰보세요. 정답 맞추신 분 댓글 달아주세요!" |

**규칙:**
- 영상 내용의 핵심 논점이나 가장 논쟁적/흥미로운 포인트를 건드릴 것
- 시청자가 자연스럽게 **자기 생각을 쓰고 싶어지는** 형태
- "구독해주세요" 같은 CTA는 넣지 않음 (설명글 CTA와 분리)
- 너무 길면 안 읽음 → 간결하게
